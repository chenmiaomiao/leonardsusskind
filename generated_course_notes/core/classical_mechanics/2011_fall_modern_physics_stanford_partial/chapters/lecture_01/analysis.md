2. Stroboscopic time and finite state sets expose that framework without continuous mathematics.
3. Reversible deterministic maps have one arrow in and one arrow out at every state.
4. Disconnected trajectories support conserved labels, while merging trajectories erase information.
5. A state must include every datum used by the law; for a particle this means position and velocity.
6. Finite measurement precision limits prediction without changing exact determinism.
7. The order of a differential equation counts the independent initial data required.
8. The corrected two-step coin rule makes state enlargement and reversibility explicit on four ordered pairs.
