# Visual Validation

## Selection Standard

Every retained frame was checked against the adjacent transcript and video.
A frame must show the relevant completed board state, remain useful at print
size, and advance the derivation.  Title cards, campus views, generic
lecturer shots, unfinished equations, and residual chalk unrelated to the
nearby argument are excluded.
